The dataset used is: 
**`Online Sales Data.csv`**
#Steps Performed

1. **Load & Explore**  
   - Check data types and missing values.

2. **Handle Missing Values**  
   - Numerical: Imputed with mean  
   - Categorical: Imputed with most frequent value

3. **Encode Categorical Features**  
   - Label Encoding used

4. **Standardize Numerical Features**  
   - Scaled using StandardScaler

5. **Remove Outliers**  
   - Visualized with boxplots  
   - Removed using IQR method

## Libraries Used

- pandas, numpy  
- seaborn, matplotlib  
- sklearn (Imputer, Scaler, Encoder)
